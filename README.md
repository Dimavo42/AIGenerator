Qwen AI Launcher

This project provides a simple Windows launcher for running the Qwen AI application.

The setup script will:

Check if Python is installed
Create a local .venv virtual environment
Install the required Python packages from requirements.txt
Launch the Python GUI application without keeping the terminal window open
Installation
Open the folder where you want to download the project.
Open CMD in that folder, or use the cd command to navigate to it.
Clone the repository:
git clone https://github.com/Dimavo42/AIGenerator.git
Open the cloned AIGenerator folder.
Double-click:
start.bat
