Ollama AI Launcher

This project provides a simple Windows launcher for running the Ollama AI application.

The setup script will:

1) Check if Python is installed
2) Create a local .venv virtual environment
3) Install the required Python packages from requirements.txt
   
Launch the Python GUI application without keeping the terminal window open


Installation:
1) Open the folder where you want to download the project.
2) Open CMD in that folder, or use the cd command to navigate to it.
3) Clone the repository:                                 git clone https://github.com/Dimavo42/AIGenerator.git
4) Open the cloned AIGenerator folder.
5) Double-click: start.bat
